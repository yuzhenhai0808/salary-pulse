# 首版落地状态

目标：Apple Silicon Mac，macOS 13+ 为构建最低版本。本机测试系统为 macOS 27.0.1；macOS 13 的实际运行仍需验证。不构建 Intel、Windows 或 Linux 版本。

## v0.1.0 私有部署与自动联动

尚未发版，后续迭代版本号保持 0.1.0，覆盖同名安装包，不另存旧版本回退。个人配置的安全备份与格式兼容仍保留，避免升级丢失私人数据；这不属于安装包版本回退。

当前需求已收敛为完全私有、本机安装使用。不需要 Apple Developer 证书、公证凭据、GitHub 登录或任何 API Key；无需证书的 ad-hoc 签名由构建工具完成。不上传或发布 Release。下文涉及公开发布的描述仅是之前规划的历史边界，不是本次必需工作。

- `calculationBasis: calendar` 为新配置默认模式，按当月班次锚定日期、周排班和日期例外计算完整有薪秒数，月薪自动分摊。跨月自动换分母，夜班按开始日期月份选费率，日统计仍按自然日拆分。
- 日薪、时薪、每秒收入和整月预算由 `preview_salary` Rust 命令自动给出；表单 180ms 去抖，过期结果不覆盖最新输入。浏览器的表单预览用 decimal.js，实时计数仍为固定演示，不冒充原生引擎。
- 自动计算工作日与有薪时长，不再默认要求输入 21.75 和 8 小时；固定模式留在高级设置，旧配置无字段时保持原公式。
- 自动识别次日下班、关联休息钟点与结束时间、统计休息时长、读取 Mac 时区；月薪/时薪切换采用预览值转换金额。
- 有薪休息是否扣减、真实工作日和特殊休息日期仍由用户决定，程序不假设法定节假日、加班倍率或货币兑换。
- 配置格式 2 含折算模式；格式 1 可读，首次主动保存升级到 2并保留备份，旧应用不应覆盖新配置。

完整月预览不等于用户当前已累计金额；月中启用、改薪与后续生效仍只计算有效时段。

## 对技术框架 v1.2 的明确调整

1. 计薪配置、开始时间及少量近期规则边界保存在同一个 `config.json`，备份为 `config.json.bak`；没有相互依赖的 `config.json + state.json` 提交流程。辅助提醒 ID 独立存 `notifications.json`，不影响金额恢复。
2. 薪资/排班修改统一不早于后续自然日午夜生效，按旧夜班结束时间检查安全边界。未开始的旧自然日班次在边界后不再使用，不允许当天新旧排班重叠。已开始的班次按开始时适用规则完成。
3. 语言/主题变更不会改业务规则 ID；窗口位置保存不增加表单 revision，提交设置时保留后端最新位置。
4. 已开始估算后暂不允许更换时区；需要明确删除个人数据后重新配置，避免跨时区日统计混淆。
5. 下班提醒只提供应用开关与测试按钮，不把 Tauri 的桌面 `Granted` 当作 macOS 真实权限；调用成功也不代表通知已送达。
6. 用原创 Canvas 2D 机器人代替位图角色，资源和代码全部离线；不使用外部图片或音乐。
7. 首版按全局系统首选语言解析 `system`；未读取 macOS 单应用语言覆盖。这一高级行为仍需原生桥接验证。
8. 当前只提供本机测试包，使用 ad-hoc 签名，没有 Developer ID 签名或 Apple 公证，不可宣传为无警告的公开正式版。
